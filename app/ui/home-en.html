What this node offers and what the registered nodes offer, each with whoever offers it. This page is browse-only: negotiating a contract and downloading the data happen in the console, signed in.

What this is

A data space is not an open catalogue: it is a place where access to each piece of data is governed by a policy and closed by a contract. Publishing is not exposing, and downloading requires having negotiated.

Each node belongs to whoever installed it. This node publishes its own offer and, when it registers another node's address, that node's offer joins this catalogue. That is how several organisations that installed this separately become one data space.

Two controls hold that up, and both can be checked: a completed negotiation is required to download, and delivery destinations are restricted. Every operation and every refusal is recorded.

Scope

This node runs My Open Dataspace, which demonstrates concrete publication, discovery, negotiation, transfer and evidence scenarios. It does not certify conformance, does not guarantee universal interoperability, and does not accredit membership of any initiative.
